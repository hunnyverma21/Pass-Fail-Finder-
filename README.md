# Pass or Fail Finder

A beginner-friendly Python project that checks whether a student has passed or failed based on their marks.

## Features
- Accepts marks from 0 to 100.
- Uses **40 marks** as the passing threshold.
- Displays PASS or FAIL.
- Handles invalid numbers and marks outside the valid range.

## Requirements
- Python 3.x

## How to Run
1. Make sure Python is installed.
2. Open a terminal in this project folder.
3. Run:

   ```bash
   python main.py
   ```

4. Enter marks when prompted.

## Example
```text
Enter your marks (0-100): 65
Result: PASS (You scored 65/100)
```

## Customization
Change `PASS_MARKS = 40` in `main.py` if your institution uses a different passing mark.
